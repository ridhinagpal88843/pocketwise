# PocketWise – Student Budget Tracker

PocketWise is a responsive, frontend-only budget management website designed to help students track their income, manage expenses, and develop better financial habits.

## Features
- Add income and expense transactions.
- View total income, expenses, and available balance.
- Organize transactions by category.
- Set and manage a budget.
- View spending patterns through a donut chart.
- Browse and delete transaction history.
- Save financial data automatically using browser LocalStorage.

## Technologies Used
- HTML5
- CSS3
- JavaScript
- LocalStorage

## How to Run
1. Download or clone the project repository.
2. Open the `pocketwise` folder.
3. Open `index.html` in a web browser.
4. Alternatively, use the VS Code Live Server extension.

## Deployment
PocketWise can be deployed independently using Vercel.

- Framework Preset: Other
- Build Command: Leave blank
- Output Directory: `.`

## Project Type
Frontend-only web application. No backend or database is required. Financial data is stored locally in the user's browser. It is not connected to bank accounts.
